# Компоненты Go

Прикладное ядро OneTunnel разделено на пользовательский хост профилей и привилегированную сетевую службу. Пользовательское DPAPI-хранилище остаётся в контексте пользователя; операции маршрутизации, DNS и WFP выполняются службой.

| Пакет | Ответственность |
| --- | --- |
| `internal/profiles` | Импорт, подписки, группы, Unicode, проверка и хранение профилей |
| `internal/protocol` | Проверка протоколов и генерация конфигураций |
| `internal/control` | Контракт IPC, команды, состояние и последовательное выполнение операций |
| `internal/platform` | Windows-сеть, жизненный цикл движков, защита и восстановление |
| `internal/embeddedxray` | Встроенный Xray |
| `internal/embeddedsingbox` | Встроенный sing-box |
| `internal/embeddedawg` | Встроенный AmneziaWG и обычный WireGuard |

WPF и OneTunnel.Presentation содержат интерфейс, модели представления и передачу команд. Эталонные C#-реализации в tests/LegacyCore используются для проверок совместимости и не входят в приложение.

## Совместимость

Идентификаторы протоколов, схема пользовательского документа и версия API управления независимы от номера выпуска приложения. Смена версии приложения не меняет формат профилей.

Восстановление получает исполняемые пути из доверенной установки, а не из журнала. Совместимость с прежними журналами обеспечивается отдельными путями очистки. Внешние движки остаются вариантом сборки для разработки.

## Проверки

Тесты охватывают генерацию конфигураций, импорт, подписки, DPAPI, атомарное хранение, IPC, жизненный цикл движков и восстановление. Проверки всей системы используют независимый процесс восстановления с ограниченным временем выполнения. Этот механизм относится к тестовой инфраструктуре; в рабочем kill switch нет таймера автоматического снятия защиты.
