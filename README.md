# OneTunnel

OneTunnel — VPN-клиент для Windows с ядром на Go и интерфейсом WPF. Приложение объединяет AmneziaWG, WireGuard, VLESS, SOCKS5, Hysteria2 и Shadowsocks в одной оболочке.

## Возможности

- Локальный прокси и режим «Всё устройство».
- Автоматическое распознавание конфигураций и ссылок, импорт подписок HTTPS/JSON/Base64.
- Группы профилей, обновление подписок, поддержка эмодзи и флагов стран.
- VLESS TCP/RAW, WebSocket, gRPC, HTTPUpgrade, XHTTP/SplitHTTP, KCP и Hysteria transport; TLS и REALITY.
- Фрагментация TLS, шумы UDP и MUX для совместимых транспортов.
- Зашифрованное локальное хранение профилей и настроек через Windows DPAPI.
- Постоянный kill switch в режиме «Всё устройство».

Серверы и учётные данные не входят в приложение. Одновременно активно одно подключение. Режим локального прокси обслуживает приложения, использующие его адрес; системный прокси Windows не изменяется.

## Архитектура

| Компонент | Назначение |
| --- | --- |
| WPF / C# | Интерфейс, отображение состояния и локальный IPC |
| Go-хост профилей | Импорт, подписки, проверка данных и пользовательское хранилище |
| Windows-служба на Go | Подключения, маршруты, DNS, kill switch и восстановление |
| Встроенные движки | Xray, sing-box и AmneziaWG; обычный WireGuard использует AmneziaWG |

Интерфейс отделён от ядра. Управление службой осуществляется через аутентифицированный локальный канал. Закрытие интерфейса не останавливает подключение. При аварии ядра блокировка трафика сохраняется до явного отключения или восстановления.

Архитектурный ориентир — [bimeron-core](https://github.com/bimeron/bimeron-core): независимое ядро, отдельные интерфейсы и документированная граница интеграции. Реализация и поддерживаемые платформы OneTunnel описаны в этом репозитории.

## Платформа и сборка

Windows 10/11 x64. Для сборки используются .NET 10 SDK, PowerShell и Go; версия Go закреплена в скриптах проекта. Пакет Windows включает среду .NET и встроенные движки.

```powershell
./scripts/Setup-Emoji.ps1
./scripts/Build.ps1 -Name OneTunnel-0.1.0-win-x64
```

```powershell
cd GoCore
go test -p 1 ./... -tags embeddedxray,embeddedsingbox,embeddedtun,embeddedawg,with_quic,with_gvisor
```

Установка и обновление Windows-службы требуют прав администратора. Установщик допускает обновление только при отсутствии активного подключения и незавершённой блокировки.
